Four AI agents. One shared goal. No agent has the full picture. This page explains how it all works — in plain English, no jargon.

Everyone's state updates

The six things that drive everything
Every outcome emerges from these
🤝
Trust
Trust (0–1): High = shares freely. Low = guarded. High trust = shares freely. Low trust = refusals and silence. Updates every single tick.
😰
Stress
Rises when refused, challenged, or ignored. Falls when cooperation happens. High stress triggers a strategy switch. Stay stressed long enough and the group can melt down.
🧩
Strategy
Agents switch between cooperative, defensive, avoidant, and confrontational based on their current emotional state. You can watch it change live on the dashboard.
💬
Emotion Detection
Every message is read by an AI emotion model. The detected emotion — disapproval, gratitude, nervousness — directly changes how the receiving agent responds next. Turn emotion analysis off to run a baseline comparison.
🎯
Tasks
Each agent starts with exactly one item. The group can only succeed if all four share. Every piece has to come through real conversation — there's no shortcut.
🏁
Outcomes
Five ways a run can end — none predetermined. Which one depends entirely on what the agents do.
✓ Success⬡ Partial✕ Failure⊗ Deadlock⚡ Meltdown
