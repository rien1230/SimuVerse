What makes it a research tool

Built for observation, not just simulation

SimuVerse shows its work. Every decision is explained, every intervention is measured, and every run can be reproduced exactly.

🔍

Explainable agent decisions

Every action in the simulation log includes a Why and an Effect — what drove the decision and what it changed in the team. No black boxes.

⚡

Live interventions

Influence the team mid-run: reveal information, force a meeting, adjust pressure. Each intervention is tracked with before-and-after metrics so you can see what actually changed.

📊

Repeatable experiments

Run the same scenario with different team types and compare outcomes side by side. Stress, trust, cohesion, and conflict events are captured automatically across every run.

🗂️

History and replay

Every completed run is saved. Revisit the full event timeline, inspect past decisions, and compare outcomes across runs — without having to rerun the simulation.

How it works

From setup to replay in five steps

1

Choose a scenario

Pick the environment and task structure that fits what you want to study.

2

Set the team

Select a personality preset or build a custom team from four agent profiles.

3

Run and intervene

Step through manually, apply interventions mid-run, or let it run automatically.

4

Inspect behaviour

Pause, step through, and inspect how trust, stress, cooperation, and conflict change during the run.

5

Review and replay

Every run is saved. Revisit any past run, compare outcomes, and export the metrics.

Before you continue

SimuVerse is an academic multi-agent simulation platform. Data generated here — agent decisions, metrics, and run histories — is used for research purposes only and is stored locally in your browser.

No personal data is collected. Runs are identified by anonymous IDs. You can delete all data at any time from the History page.

By continuing you acknowledge you understand the nature of this simulation tool.
